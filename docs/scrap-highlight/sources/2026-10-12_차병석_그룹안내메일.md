# [원문 요약] 차병석 부사장 안내 메일 — 「[안내] AI 활용 스크랩 개선 사례 공유 및 각사 적용 요청」

- 발신: 차병석 부사장/팀장/브랜드PR팀 (bs.cha@samsung.com)
- 일시: 2026-10-12 17:19 → 김인철 상무 FW 10-13 07:15 (수신에 이한정 누락)
- 첨부: `260930_스크랩_관계사_공유.pdf` (샘플)
- 배경: 10.6(화) 홍보임원회의에서 언급. 그룹 스크랩에 9.14(월)부터 적용 운영 중

## 기능 개요
- 스크랩 PDF에서 기사 핵심 문장을 AI가 자동 하이라이트 (경영진 열람 시간 단축, 가독성)
- 그룹 개발·테스트 약 8주(7.20~9.12) → 9.14 적용
- 프로그램은 그룹 스크랩 양식 + 전자 AX개발팀 인프라 기준 → **관계사는 각사 포맷에 맞게 자체 개발**
- **권고 일정: 10월 개발착수 → 11월 테스트 → 12월 적용 (목표 연내)**, 각사 커뮤니케이션팀 주관

## 하이라이트 원칙
1. 기사 제목/부제와 관련된 본문 주요 문장 표시
2. 동일 이슈 여러 매체 연속 수록 시, 두 번째 기사부터는 앞 기사와 중복되지 않는 핵심 문장만 (사진기사·그래픽 제외)
   - 샘플 p.1~4 벤플리트 시상식 4개 매체 / p.5~6 헬릭스 투자 2개 매체

## 사용자 인터페이스
- 입력 폴더(순서 잡힌 스크랩 PDF + `set.txt`) / 출력 폴더 지정 → 실행 → **150p 기준 5~7분** 후 하이라이트 PDF 생성

## 자동 처리 과정
| 단계 | 내용 | 필요 환경 |
|---|---|---|
| ① 레이아웃 분석·OCR | 스캔 PDF 글자 인식, 제목·부제·본문·사진 영역 구분 | 고성능 GPU 서버 (전자는 AX개발팀 서버/솔루션) |
| ② AI 판단 | 하이라이트 원칙에 따라 핵심 문장 선별 | 외부 AI 서비스 (ChatGPT 모델) |
| ③ 결과물 생성 | 선별 문장 위치에 하이라이트 입혀 PDF 출력 | 일반 PC (고사양 권장) |

## 개발 노하우
- **동일 이슈 묶음 구간은 사람이 지정**: AI 자동 판별은 느림 → 입력 폴더 `set.txt`에 쪽 범위 기재
  ```
  - 밴플리트상 관련 : 1~4P
  - 헬릭스 투자 관련 : 5~6P
  ```
- **Adobe 호환**: 오류 하이라이트 삭제/수동 추가를 Acrobat에서 가능
- **실무자 수기 하이라이트 샘플을 AI 학습용으로 제공**
