### 핵심 판단
- 그룹은 0→1 개발에 8주. **DX는 개발 없이 바로 적용 가능 판정**(10.12 샘플 당일 테스트) → 남은 건 PC·계정·보안 세팅뿐
- 따라서 DS도 **양식이 그룹/DX와 유사하면 개발 거의 없이 "세팅 과제"**가 됨 → 샘플 테스트 결과가 일정의 분기점
- DS 고유 리드타임은 **보안 절차(방화벽·NASCA)와 GPT Tier 4 계정** → 공식 요청과 무관하게 **지금 바로 착수 가능**
