# scrapdraft — 조간 스크랩 검토 초안 도구

스크랩마스터5에서 내보낸 **검색결과 엑셀**을 넣으면 선택·소제목·순서가 잡힌 **검토 초안 엑셀**을 만듭니다.
스크랩마스터 내부 파일이나 통신은 건드리지 않고, 공식 [엑셀 저장] 결과만 읽습니다.
확정 스크랩 변경·배포는 하지 않습니다.

## 1. 설치 (사내 PC, 최초 1회)

```bat
cd tools\clipping
pip install -r requirements.txt
copy config.example.yaml config.yaml
```

`config.example.yaml`은 일반 예시입니다. 실제 팀 설정(소제목·소주제 순서, 기획면 제외, 신문별 가판 시각, 키워드)은 저장소에 올리지 않고 사내 PC의 `config.yaml`에만 둡니다.
현안은 `issues.yaml`(만료일 필수), 그날만 쓰는 지시는 `today.yaml`로 따로 둡니다.

## 2. 스크랩마스터에서 검색결과 엑셀 저장

1. [검색] 탭에서 자동검색 결과를 새로고침합니다.
2. 검색결과 전체를 선택한 뒤 [엑셀 저장]을 누릅니다. 결과가 1000건을 넘으면 페이지마다 전체 선택해야 합니다.
3. 저장 옵션에서 **기사 제목, 부제목, 매체명, 지면번호, 발행일, 구분, 크기, 검색어, 기사 시리얼**을 체크합니다.
   - 저장 옵션은 계정 단위로 동기화되므로 한 번 맞춰 두면 됩니다.

## 3. 초안 만들기

엑셀 파일을 `run_recommend.bat` 위로 끌어다 놓거나, 다음 명령을 실행합니다.

```bat
python -m scrapdraft recommend 검색결과.xlsx --date 2026-11-02
```

뉴스 탭에서 지면은 들어왔는데 해당 기사가 없는 신문은 `--confirmed-empty 신문B`로 알려 줍니다.
그래야 그 신문을 '미수집'과 구분해 '0건(수집 확인)'으로 처리합니다.

결과는 `output\검토초안_날짜_run번호.xlsx`로 저장되고, 시트는 다음과 같습니다.

| 시트 | 내용 |
|---|---|
| 추천목록 | 추천순번·소제목·소주제·매체·면·제목·점수·선정 사유·관련기사 묶음·목차 표시(표시/숨김)·이번 실행 신규 여부 |
| 참고(기준미달·확인필요) | 점수 미달이거나 지면/온라인 구분이 없는 기사(삭제하지 않음) |
| 제외·중복 | 온라인 기사, 가판 중복(본판에 연결), 제외 키워드 기사 |
| 신문별 상태 | 결과 있음 / 0건(수집 확인) / 휴간 / 수집 전(예정 시각) / 가판 없음 / **미확인(0건 또는 미수집)** |
| 실행 정보 | 입력 파일, 건수, 전체 상태, 동일 입력 재실행 여부 |

하나라도 '미확인'이 있으면 전체 상태는 `부분 완료 (N/M)`로 표시되고, 종료 코드는 2입니다.

## 4. 처리 규칙

- **같은 기사**: 기사 시리얼이 같으면 1건으로 합치고 잡힌 검색어는 모두 남깁니다.
- **가판/본판**: 같은 신문, 같은 발행일에서 제목이 비슷하면 본판을 대표로 두고 가판은 '제외·중복'에 연결해 둡니다. 본판이 아직 없으면 가판을 남기고 "본판 미확인"으로 표시합니다.
- **다른 매체의 유사 보도**: 지우지 않습니다. 같은 묶음 번호를 붙이고 대표 기사 바로 뒤에 배치합니다.
- **배열 순서**: 소제목 순서 → 현안 고정(`pin_top`) → 매체 우선순위 → 면 → 기사 크기.
- **현안**: `until`이 지나면 자동으로 꺼집니다.
- **재실행**: 같은 날짜에 다시 실행해도 원장(`output\ledger.sqlite`)에 이미 있는 기사는 '신규'로 표시되지 않습니다. 이후 스크랩마스터에 담는 단계에서 이 원장으로 중복 추가를 막습니다.

## 5. 사람이 확정한 결과 기록

확정 편집의 목차를 [목차 저장 → 사용자 항목 선택]으로 엑셀 저장한 뒤(기사 시리얼, 연번 포함) 다음을 실행합니다.

```bat
python -m scrapdraft diff 확정목차.xlsx --date 2026-11-02
```

결과는 추가 / 제외 / 순서 이동 / 유지로 기록됩니다. 규칙은 자동으로 바뀌지 않습니다.

## 6. 과거 완성본 분석

과거 목차 엑셀을 한 폴더에 모은 뒤 다음을 실행합니다.

```bat
python -m scrapdraft analyze 과거목차폴더
```

매체 순서 추정, 소제목별 매체 분포, 면 분포, **기본 순서와 다르게 놓인 예외 후보**가 나옵니다.
예외 후보는 담당자가 사유(현안 등)를 확인하는 용도입니다.
완성본에 없는 기사는 '제외'로 학습하지 않습니다.

## 7. 실행 기록 확인

```bat
python -m scrapdraft status
```

중단된 실행은 "중단됨(마지막 단계: …)"으로 보입니다.

## 8. 스크랩마스터 화면 자동화 (사내 PC, 관리자 권한 터미널)

스크랩마스터가 관리자 권한으로 실행되므로 터미널도 관리자 권한으로 엽니다. `pip install pywinauto` 가 필요합니다.

| 스크립트 | 하는 일 |
|---|---|
| `sm5_read.py` | 화면 값 읽기 전용(검색어별 건수, 스크랩 그룹, 팝업, 좌표) |
| `sm5_scrap_test.py` | 지정한 행만 체크해 시험 그룹에 담기(기본 미리보기, `--go` 때만 실행) |
| `sm5_run.py` | 결과 갱신 → 후보 엑셀 저장 → 엔진 → 검토 그룹에 담기 → Serial 검증 → 추천 순서 정렬 |

`sm5_run.py --until export` 는 스크랩하지 않고 엑셀 저장과 초안 생성까지만 합니다.
검토 그룹에 사람이 직접 넣은 기사가 있으면 정렬하지 않고 추가만 합니다.
누르지 않는 버튼: 스크랩초기화, 선택삭제, 그룹 삭제, 스크랩북 덮어쓰기.
